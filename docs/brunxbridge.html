Modules Overview

Modules zijn bridge API’s die framework/resource-specifieke logica achter één interface zetten. Gebruik ze vanuit BrunxBridge in plaats van directe framework calls.

Voorbeeld

local Bridge = exports['brnx_bridge']:Bridge()

Bridge.Framework.GetPlayerName()
Bridge.Inventory.AddItem(source, 'bread', 1)
Bridge.Notify.SendNotification(source, 'BrunxScript', 'Actie gelukt.', 'success', 5000)

local Inventory = exports['brnx_bridge']:Inventory()
Inventory.AddItem(source, 'bread', 1)

Best Practices

  • Laat scripts nooit direct afhankelijk zijn van qbx_core, qb-core, es_extended, ox_inventory, ox_target of qb-target als de bridge dezelfde actie kan uitvoeren.
  • Gebruik server modules voor server-only acties zoals inventory mutaties, money mutaties en server dispatch alerts.
  • Gebruik client modules voor UI, target, zones, fuel, weather, progressbar, menu, input en lokale player checks.
  • Hou deprecated functies alleen aan voor oude scripts. Nieuwe scripts gebruiken de primaire functie uit de module.
