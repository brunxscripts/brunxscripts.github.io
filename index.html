One bridge for modern FiveM resources.

Brunx Bridge is a future-proof compatibility layer for ESX, QBCore, Qbox, OX, vRP and standalone resources. It centralizes framework detection, job checks, money handling, inventory helpers, target zones, UI helpers, callbacks and configurable elevators.

local Bridge = exports['brnx_bridge']:GetBridge()

RegisterCommand('bridgejob', function(source)
    local job = Bridge.GetJob(source)
    print(json.encode(job))
end, false)

-- Client-side usage
local Bridge = exports['brnx_bridge']:GetBridge()
Bridge.Notify({

    description = 'Client bridge loaded.',
    type = 'success'

What it does

Instead of writing separate code for every framework, inventory, target and UI system, your scripts can call Brunx Bridge once and let the bridge normalize the differences.

Framework abstraction

Detects Qbox, QBCore, ESX, OX, vRP or standalone mode and exposes normalized player, identifier, name, job, grade, duty and money helpers.

Inventory helpers

Provides simple server-side item helpers with ox_inventory support and player function fallback for compatible frameworks.

Target fallback

Uses ox_target when available, qb-target when available, and a drawtext interaction fallback when no target resource is running.

UI layer

Uses ox_lib for notifications, progress bars, context menus and text UI, keeping UI usage consistent across resources.

Callbacks

Wraps ox_lib callback registration and client triggering so scripts can use one consistent pattern.

Elevators

Includes a configurable elevator system with global elevators, map-specific elevators, job locks, boss locks, progress bars and carry support.

Installation

Install the bridge before any resource that depends on it.

1. Download

Download the latest main branch archive and extract it into your FiveM resources folder.

Download Bridge

2. Rename folder

Make sure the folder name is exactly:

brnx_bridge
server.cfgLoad order matters
# Required dependency
ensure ox_lib

# Optional, depending on your stack
ensure oxmysql
ensure ox_inventory
ensure ox_target
# ensure qb-target

# Framework should be started before the bridge when possible
ensure qbx_core
# ensure qb-core
# ensure es_extended

# Bridge
ensure brnx_bridge

# Your scripts that use the bridge
ensure your_resource

Important: ox_lib is required by the resource manifest. oxmysql is included as a server script dependency path, so keep oxmysql available if you use database-backed bridge features or other resources that depend on it.

Configuration

Edit shared/config.lua. Use auto unless you want to force a specific framework, inventory or target system.

Config.Debug = false
Config.Locale = 'nl'

-- auto, qbox, qbcore, esx, ox, vrp, standalone
Config.Framework = 'auto'

-- auto, ox_inventory, qb-inventory, lj-inventory, ps-inventory,
-- qs-inventory, origen_inventory, codem-inventory, core_inventory,
-- mf-inventory, esx_inventory, standalone
Config.Inventory = 'auto'

-- auto, ox_target, qb-target, drawtext

Usage examples

These examples are designed for scripts that depend on brnx_bridge.

Server: job lock

local Bridge = exports['brnx_bridge']:GetBridge()

RegisterNetEvent('my_resource:server:openArmory', function()
    local src = source

    if not Bridge.HasJob(src, {
        police = { minGrade = 1, dutyOnly = true },
        police_be = true,
        marechaussee = true
    }) then
        Bridge.Notify(src, {
            title = 'Access denied',
            description = 'You are not allowed to open this armory.',
            type = 'error'
        })
        return
    end

    Bridge.Notify(src, {
        title = 'Armory',
        description = 'Access granted.',
        type = 'success'
    })
end)

Server: items and money

local Bridge = exports['brnx_bridge']:GetBridge()

RegisterNetEvent('my_resource:server:buyKit', function()
    local src = source
    local price = 750

    if Bridge.GetMoney(src, 'bank') < price then
        Bridge.Notify(src, {
            title = 'Payment failed',
            description = 'Not enough money in your bank account.',
            type = 'error'
        })
        return
    end

    if Bridge.RemoveMoney(src, 'bank', price, 'buy-kit') then
        Bridge.AddItem(src, 'repairkit', 1)
        Bridge.Notify(src, {
            title = 'Purchase complete',
            description = 'You received a repair kit.',
            type = 'success'
        })
    end
end)

Client: target zone with fallback

local Bridge = exports['brnx_bridge']:GetBridge()

CreateThread(function()
    Bridge.Target.AddBoxZone('cityhall_counter', {
        coords = vec3(-545.45, -203.88, 38.22),
        size = vec3(2.0, 1.2, 2.0),
        rotation = 30.0,
        distance = 2.0,
        options = {
            {
                name = 'open_cityhall',
                label = 'Open City Hall',
                icon = 'fa-solid fa-building-columns',
                onSelect = function()
                    TriggerEvent('my_cityhall:client:open')
                end
            }
        }
    })
end)

Client: progress bar

local Bridge = exports['brnx_bridge']:GetBridge()

local completed = Bridge.Progress({
    duration = 5000,
    label = 'Processing...',
    canCancel = true,
    disable = {
        move = true,
        car = true,
        combat = true
    }
})

if completed then
    Bridge.Notify({
        title = 'Done',
        description = 'The action completed successfully.',
        type = 'success'
    })
end

Elevator system

Brunx Bridge includes global elevators and map-specific elevators. Floors support job locks, job type locks, minimum grades, boss-only access and optional hiding for unauthorized players.

Config.Elevators = true
Config.DrawDistance = 10.0
Config.InteractDistance = 2.0
Config.ElevatorProgressDuration = 5000
Config.ElevatorProgressLabel = 'Lift wordt gebruikt...'
Config.ElevatorCarryEnabled = true
Config.ElevatorCarryDistance = 3.0
Config.ElevatorCarryCuffedOnly = false

Config.GlobalElevators = {
    {
        name = 'Example Elevator',
        showMarker = true,
        floors = {
            {
                label = 'Lobby',
                coords = vector4(0.0, 0.0, 30.0, 0.0),
                jobLock = nil
            },
            {
                label = 'Management',
                coords = vector4(0.0, 0.0, 40.0, 0.0),
                jobLock = {
                    enabled = true,
                    hideIfNoAccess = false,
                    jobs = {
                        police = { minGrade = 3, bossOnly = true },
                        ambulance = { minGrade = 4 }
                    },
                    jobTypes = {
                        leo = { minGrade = 3 },
                        ems = { minGrade = 4 }
                    }
                }
            }
        }
    }
}

jobLock.jobs

Use job names as keys. Value can be true, a minimum grade number, or a table with minGrade, bossOnly and dutyOnly.

jobLock.jobTypes

Use normalized job types such as leo or ems when your framework exposes a job type.

hideIfNoAccess

When true, unauthorized floors can be hidden from the menu instead of shown as locked.
